Componente: ui/screens/components/SesionesDelDiaCards.kt

El usuario siempre ve información actualizada sin necesidad de recargar manualmente. Los estados visuales cambian en tiempo real (⏰ → ▶️ → ✅).

Anatomía Visual de una SesionesDelDiaCard

Card(

6. SuggestionChips

Extraído de ChatScreen.kt líneas 962-1050:

Implementación

Row(
    modifier = Modifier
        .fillMaxWidth()
        .horizontalScroll(rememberScrollState())
        .padding(horizontal = 12.dp, vertical = 8.dp),
    horizontalArrangement = Arrangement.spacedBy(8.dp)
) {
    suggestions.forEach { suggestion ->
        SuggestionChip(
            onClick = {
                vm.disableSuggestionsForMessage(index)
                vm.sendMessage(suggestion.displayText)
            },
            label = { Text(suggestion.displayText) },
            enabled = !ui.loading && m.suggestionsEnabled
        )
    }
}

Tipos de Sugerencias

Tipo Comportamiento Ejemplo
Navegación (pagination) Chips con iconos de flecha (prev/next), ordenados por dirección ← Página anterior | Página siguiente →
Acciones contextuales Chips sin icono, texto descriptivo "Ver clases de ayer", "Buscar alumno"
Filtros Chips que envían mensaje con contexto adicional "Solo alumnos activos", "Solo completadas"
Deshabilitar sugerencias: Cuando el usuario hace tap en un chip o escribe un nuevo mensaje, se llama a vm.disableSuggestionsForMessage(index) para que los chips del mensaje anterior desaparezcan (evita saturación visual).

7. Estados de Carga

Extraído de ui/screens/components/TypingIndicator.kt:

TypingIndicator (Animación de 3 Puntos)

@Composable
fun TypingIndicator(dotColor: Color = Color(0xFF555555)) {
    // 3 dots animados con offset vertical
    Row(spacing = 4.dp) {
        Box(
            modifier = Modifier
                .size(8.dp)
                .offset(y = offsetY1.dp)  // animateFloat 0f → -8f
                .background(dotColor, CircleShape)
        )
        Box(
            modifier = Modifier
                .size(8.dp)
                .offset(y = offsetY2.dp)  // delay 200ms
                .background(dotColor, CircleShape)
        )
        Box(
            modifier = Modifier
                .size(8.dp)
                .offset(y = offsetY3.dp)  // delay 400ms
                .background(dotColor, CircleShape)
        )
    }
}

Uso del TypingIndicator

Contexto Ubicación
Mensaje de bienvenida inicial Centrado en pantalla vacía dentro de Card blanco con elevation 4.dp
Respuesta en proceso Última burbuja del asistente (blanca) mientras ui.loading == true
Animación: infiniteRepeatable con tween(600ms), RepeatMode.Reverse, efecto de "ola" vertical (-8dp offset).

9. Interacciones Clave

1. Pasar Lista (AlumnosSesionTable)

Flujo de interacción:
1️⃣ Usuario hace tap en botón "Pasar lista" desde tarjeta de sesión
2️⃣ Chat muestra tabla interactiva con checkboxes (✅/❌) por cada alumno
3️⃣ Usuario toca checkboxes para marcar ausencias - cambio visual instantáneo
4️⃣ Botón "Confirmar Asistencia" se activa en footer de tabla
5️⃣ Al confirmar, aparece indicador de carga (TypingIndicator)
6️⃣ Feedback visual: Resumen de asistencia con nuevas opciones de acción

2. Ver Detalles (Modal BottomSheet)

Flujo de interacción:
1️⃣ Usuario hace tap en icono 🔍 en cualquier fila de tabla
2️⃣ Aparece panel deslizante desde abajo (BottomSheet) con animación suave
3️⃣ Muestra todos los campos del registro en formato legible
4️⃣ Usuario puede cerrar tocando fuera del panel o arrastrando hacia abajo
5️⃣ Animación de cierre con efecto de deslizamiento 
if (ui.detailsItem != null) {

        }
    }
}

3. Aclaración de Sugerencias (Diálogo Interactivo)

Experiencia de usuario:
• Cuando una acción requiere información adicional, aparece un diálogo emergente
• Campo de texto pre-rellenado con el texto de la sugerencia seleccionada
• Usuario puede editar o ampliar el mensaje antes de enviar
• Botones "Cancelar" (cierra sin enviar) y "Enviar" (confirma acción)
• Feedback visual inmediato: diálogo se cierra y mensaje aparece en el chat

Interacciones del formulario:

  • Enviar/Guardar: Valida campos, muestra indicador de carga, confirma con mensaje de éxito

  • ✅ Una sola pantalla (ChatScreen) post-login

  • ✅ Tarjetas contextuales (SesionesDelDiaCards, CompactList, AlumnosSesionTable)
  • ✅ Interacción directa (checkboxes en tablas, botones en tarjetas)
  • ✅ Feedback visual (TypingIndicator, ModalBottomSheet, Snackbars)
  • ✅ Paleta WhatsApp (#128C7E, #DCF8C6, #ECE5DD) para familiaridad
  • ✅ Material Design 3 con Jetpack Compose nativo
